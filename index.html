      実データテスト順序
      1. setupInitialAdminPassword 実行後、_sys_account の password_hash が空欄でなく、must_change_password が TRUE、updated_at が更新されていることを確認します。
      2. HTMLを開き、_sys_account.login_id と設定した仮パスワードでログインします。
      3. ログイン成功後、社員一覧ではなく「パスワード変更が必要です」パネルだけが操作対象になることを確認します。
      4. 現在のパスワードに仮パスワード、新しいパスワードと確認入力に同じ新パスワードを入力して変更します。
      5. 変更成功後、社員マスタ画面が表示され、_sys_account.must_change_password が FALSE、password_hash と updated_at が更新されていることを確認します。
      6. ログアウト後、旧仮パスワードではログイン失敗、新しいパスワードではログイン成功になることを確認します。
      7. 誤った現在パスワード、7文字以下、不一致確認入力、同一パスワードで更新がブロックされ、password_hash が変化しないことを確認します。
      8. 操作ログ・GAS実行ログ・APIレスポンスに平文パスワードとpassword_hashが含まれていないことを確認します。

        3. GAS接続確認 を押し、_sys_employment_type の is_regular_employee ヘッダー不足が出ないこと、必要に応じて _sys_account / _sys_account_role の診断が表示されることを確認します。
        4. 画面上部のログイン確認欄で、ログインID・パスワードを入力し、loginEmployee API への送信結果が表示されることを確認します。
        5. must_change_password が TRUE の初回ログインではパスワード変更画面だけが操作でき、変更成功後は新しい認証トークンで社員マスタ本体へ進めることを確認します。通常ログインではログイン入力欄がロックされ、ログアウトボタンで未ログイン状態へ戻ることを確認します。
        6. 未ログイン時は社員マスタ本体が非表示で、ログイン成功後に社員一覧・詳細・保存操作の画面が表示されることを確認します。
        7. 保存API権限ブロックの確認として、保存系APIに account_id / login_id / role / auth_session_token が添付され、password_hash とパスワードは送らないことを確認します。
        8. 一覧再読込 を押し、スプレッドシートの社員一覧が表示されることを確認します。
        9. 社員追加・社員編集で、正社員区分欄が手入力できないこと、雇用区分を変更した時に正社員区分の確認表示がマスタ判定値に同期すること、保存結果とシート側の is_regular_employee がマスタ判定値に揃うことを確認します。
        10. 同じテスト社員で社員追加、編集、退職、無効化を順に実行し、createEmployee / updateEmployee / retireEmployee / disableEmployee がすべて成功すること、各操作後の一覧再読込で警告が出ないことを確認します。

        退職処理は m_employee.left_date / updated_at のみを更新し、status と m_employee_private は変更しません。無効化は m_employee / m_employee_private の status を inactive に更新します。

        v1.2-12では、ログイン成功時に受け取った一時認証トークンを保存系APIへ添付し、GAS側で _sys_account / _sys_account_role と照合してから保存・退職・無効化を実行します。

        確認対象の目安: 正社員の雇用区分を選ぶと確認表示が「はい」、パート・アルバイト等を選ぶと「いいえ」へ同期すること。既存社員の編集では、保存前後で正社員区分がフォーム手入力ではなくマスタ判定値に揃うことを確認します。退職処理は left_date と updated_at 以外を変更しないことも確認対象です。

        失敗時は、GASの再デプロイ漏れ、Webアプリのアクセス設定、スプレッドシートID/紐づけ、シート名、ヘッダー名、社員番号重複、code項目不足、_sys_マスタ未登録を順番に確認してください。
